### ⚠ Caveats for the RAY_ cases

1. **The stored CFcases are not the configuration Ray ran.** Each job stdout on VSC echoes the full effective configuration. Comparing them shows that the stored files often have `MaxIter = 1`, tiny CFLs and other restarts or meshes. The job runs used `MaxIter = 1e10`, different CFL ramps, different LLAV parameters (S0, κ, Péclet), different interactive files and different restart files.
   - I extracted the effective configuration of the **last job** of each family, unchanged, into `AS_RUN_on_VSC_<job>.txt` inside the matching case folder. It is a `key value` list, not a CFcase.
   - **For reproducing Ray, the AS_RUN file is the reference. The stored CFcase is a starting point only.**
2. **Interactive files.** Almost none of Ray's `*.inter` files survive; only `Cone/transition.inter`, `cone.inter` and `FlatPlate/transition.inter` exist. COOLFluiD aborts if the interactive file is missing (`ConfigFileReader` throws "Could not open file"). Where the original was missing, I created a **placeholder** with the original name. It contains only comment lines saying it is a placeholder. Ray's runtime overrides (CFL, MaxIter, LLAV, wall BC switches) are therefore lost, except where the AS_RUN echo shows the final values.
3. **Missing restarts.** Most restart solutions named in the AS_RUN files are gone (HIFiRE P1–P4, DiCristina 3D P1–P3, Kimmel 3D P2/P3, Kimmel 2D P0). See the per-case notes.
4. **`MaxIter = 1`** is set in the stored CFcase of: Kimmel 2D P1/P3/P4/P5, Kimmel 3D P1/P3, DiCristina 2D P2, DiCristina 3D P1 explicit, HIFiRE P1, HEXAFLY P1 and laminar NS P0/P1. As copied, these run one iteration and write output. Set `MaxIter`, either in the CFcase or in the placeholder `.inter` file, before a real run.

## How to run

Ray's PBS scripts (`05_reference_results_RAY/vsc_jobs/`) confirm the invocation pattern: `cd <build>/apps/Solver && mpirun -np N ./coolfluid-solver --scase <CFcase>`, with `WorkingDir` relative to the source root. All copies here were changed to `WorkingDir = ./`, so run from inside the case folder:

```bash
cd <case folder>
ln -sf /home/u0142014/Desktop/COOLFluiD/OPENMPI/optim/apps/Solver/coolfluid-solver* .
mpirun -np <N> ./coolfluid-solver --scase ./<file>.CFcase > run.log 2>&1
```

- **Libraries:** every library loaded by every copied case exists in `COOLFluiD/OPENMPI/optim/dso` [checked].
- **Binary:** this binary is the `fr-turbulence` working tree with uncommitted changes. It is **not** Ray's code (`RAY_VSC_FILES/vsc32241/COOLFluiD_Genius`, svn-era), so results may differ.
